# LLM 研究 Wiki

這是用來長期累積大型語言模型研究的 Markdown 知識庫。可將本資料夾直接開為 Obsidian Vault，或在 Codex 中把它當作工作資料夾。

1. 從 [Wiki 索引](wiki/index.md) 瀏覽研究方向與已收錄頁面。
2. 把要收錄的 PDF 放入 `raw/papers/`，或在對話提供論文網址。
3. 可以對代理說：「請依照 AGENTS.md 收錄這篇論文，摘要方法、評估設定和主要限制，並更新 Wiki 索引與紀錄。」

代理的收錄、查詢及健檢流程見 [AGENTS.md](AGENTS.md)。已收錄 [Choi 等（2024）](wiki/sources/2024-choi-metallic-implants-ct-topograms.md)。在專案中貼上或上傳後續文章即可開始收錄。

提出研究題目後，可從[研究筆記](notes/README.md)與[簡報逐頁稿](slides/README.md)接續工作。候選文獻會附在筆記文末，選定後依[維護規範](AGENTS.md)收錄。[HTML 簡報](presentations/README.md)會在風格與版型確認後製作。
