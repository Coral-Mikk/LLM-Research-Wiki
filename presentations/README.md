# HTML 簡報

確認受眾、長度與版型後，每個題目以獨立資料夾保存 `index.html` 及所需資源。預設支援離線播放。

## 預設風格

採用簡潔、略正式的醫療研究風格。預設 16:9 橫式版面，白底、深灰正文、深藍為重點色。每頁聚焦一個訊息，繁體中文為主，保留必要的英文術語。

圖表採簡約平面設計，標示單位、指標定義、評估條件與來源。需精確對照數字時使用表格。醫學影像採灰階原圖，必要時用少量箭頭或框線標示觀察位置，保留解讀所需的資訊。研究結果與臨床應用限制分別交代。

逐案討論報告對象、時間、講者備註與版面細節。

本 Wiki 採用臨床判讀型。每頁以臨床問題、可判讀的結果或適用限制為主，必要時用表格或單色長條圖呈現，並保留來源與評估條件。
